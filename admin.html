    Minimum version

    Settings

    Your account

    Admin sign-ins

    When the admin console was opened (after the authenticator code), from which browser. Kept for 400 days. Only admins are listed.

    Privacy policy versions

    The version is the "Last updated" date on the privacy page. An account's version is derived from its sign-up date; per-click consent comes with the next extension release.

    Daily digest

    One short email each morning to every owner admin: yesterday's sign-ups, active users, payments and refunds, open payment issues, new feedback and error groups, LinkedIn health, deletions due, overdue data requests and the release card. Counts only. It is switched off until it is scheduled (see the deploy guide). The preview sends nothing.

    
        
    
        
    
          
    Admin roles
    
          
    An owner can do everything. A support admin can read users and feedback, add notes and reply to feedback, but cannot grant or revoke plans, suspend or delete accounts, or see revenue and payments. Making someone an admin is a manual step in the database (see the deploy guide); here you only change the role of an existing admin. The last owner cannot be made a support admin.
